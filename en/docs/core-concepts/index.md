# Core Concepts

Stello's design centers on one question: **How do we make AI collaboration match the divergent nature of human thinking?**

Linear conversations follow a single thread, but real thinking branches in multiple directions at once. Stello explodes conversations from a line into a tree — each branch goes deep independently while a global layer maintains the big picture.

## Concept Map

| Concept | One-liner |
|---------|-----------|
| [Session & Topology](/en/docs/core-concepts/session-and-topology) | Sessions are independent conversation units; the topology tree describes their relationships |
| [Three-Layer Memory](/en/docs/core-concepts/three-layer-memory) | L3 raw conversation, L2 skill description, L1 global cognition — memory flows across layers |
| [Skill Metaphor](/en/docs/core-concepts/skill-metaphor) | Child Sessions are skills, Main Session is the orchestrator |
| [Consolidation & Integration](/en/docs/core-concepts/consolidation-and-integration) | Memory reports upward (L3→L2) and integrates globally (all L2s→synthesis+insights) |
| [Orchestration Strategy](/en/docs/core-concepts/orchestration-strategy) | Flat vs hierarchical — different ways to organize Sessions for different scenarios |

We recommend reading in order — each concept builds on the previous one.
